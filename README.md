### Hi, I'm @karloscodes

Simplifying things that don't need to be complicated.

#### Open Source

- [Fusionaly](https://github.com/karloscodes/fusionaly-oss) — Self-hosted web analytics. One SQLite file, one container.
- [Cartridge](https://github.com/karloscodes/cartridge) — Go web framework. Clean defaults, sublime developer experience.
- [Chasen](https://github.com/karloscodes/chasen) — Deploy to one server you own. HTTPS, SQLite backups, and zero-downtime deploys built in.
- [Formlander](https://github.com/karloscodes/formlander) — Self-hosted form backend. One Docker command.
